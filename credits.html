3D Body Map

The 3D body-map model used throughout this app is built on Z-Anatomy — The libre 3D atlas of anatomy, licensed under CC BY-SA 4.0, which is in turn built on BodyParts3D — The Database Center for Life Science, © Kousaku Okubo / DBCLS, licensed under CC BY-SA 2.1 Japan.

Changes made: the skin and muscle meshes were welded into single shells, decimated for real-time mobile rendering, re-normalized to this app's model space, grouped into this app's muscle-group categories, and rigged and posed to produce this app's exercise animation loops.

Dark-mode reference pass

Home tab, restyled after the wellness-app screenshot

Borrowed structurally, not copy-pasted: the confident date/greeting type scale, a horizontally-scrollable session card with a scattered "constellation" of pose icons instead of a plain progress button, a home-screen search entry point, and a Browse by Area grid — which maps 1:1 onto the ExerciseCategory enum that already exists in the codebase, so it cost nothing new to define. Every icon is still the real PoseGlyphIcon system — no illustrated full-color figures like the reference uses; that's a different, much bigger illustration commitment than one UI pass should smuggle in.

Something this surfaced, not invented: the real "Wake Up" session (Box Breathing, Cat-Cow Flow, Shoulder Roll, Standing Back Extension) has two exercises that both fall back to the generic standingNeutral archetype (Shoulder Roll and Standing Back Extension) — so in a constellation layout, two of the four nodes look identical except for the small clockwise-motion badge on Shoulder Roll. "Unwind" is worse: three of its four exercises are breathing exercises, and every breathing exercise currently resolves to the same breathSeated glyph, so three of four nodes are the same icon. That's an honest constraint of the current 16-archetype library, not a mockup bug — flagging it because a constellation layout is exactly the kind of place that makes archetype collisions visible in a way a single small icon in a list row never does.
